# Online News Classification

## Overview
This project focuses on automatic classification of online news articles into predefined categories.

## Problem
Classifying noisy, real-world online news articles is challenging due to:
- high-dimensional sparse text
- label inconsistency
- noisy HTML content
- class imbalance

## Approach
The pipeline includes:
- text cleaning
- hybrid TF-IDF features
- data consistency check
- Logistic Regression classifier

## Results
- Macro F1-score: 0.7093
- Logistic Regression outperformed LinearSVC and the ensemble baseline
